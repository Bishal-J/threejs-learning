# Three.js Learning 🚀

This repository contains my journey of learning **Three.js** by building small experiments, demos, and projects.

## Tech Stack

- 🎮 Three.js
- ⚡ Vite
- 🟦 TypeScript
- 🎨 Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

```bash
git clone https://github.com/Bishal-J/threejs-learning.git
cd threejs-learning
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local development URL shown in your terminal.

### Build for Production

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```

- Understand the fundamentals of Three.js
- Learn cameras, scenes, and renderers
- Work with geometries and materials
- Add lighting and shadows
- Explore textures and models
- Create animations
- Learn controls and interactions
- Experiment with shaders and advanced rendering techniques
